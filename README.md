# Ταβέρνα η Ελιά

Πρώτη κοπή ενός δικού μας ERP. Δεν είναι Soft1 και δεν κόβει φορολογικά παραστατικά.

Το κοινό υπόβαθρο είναι είδη, συντελεστές ΦΠΑ, παραστατικά με γραμμές, πληρωμές και κινήσεις αποθήκης. Η πρώτη χρήση είναι η εστίαση: όροφος, παραγγελία, τροποποιήσεις, εξόφληση, βάρδια. Στο κλείσιμο του τραπεζιού η συνταγή ρίχνει την αποθήκη και μένει ένα δελτίο για να χτυπηθεί το σύνολο στην ταμειακή του μαγαζιού.

Οι τιμές του μενού είναι τελικές, με ΦΠΑ. Η εμπορική διαχείριση, η λογιστική, η μισθοδοσία και η myDATA δεν είναι μέσα.

## Τρέξιμο

```bash
npm install
npm test
npm run dev
```

Άνοιξε http://localhost:3000. Ζητάει κωδικό πριν από τον όροφο. Στο δείγμα: Υπεύθυνος `8024`, Μαρία `2580`, Νίκος `1470`, Ταμείο `3690`. Ο υπεύθυνος μοιράζει δικαιώματα από τις Ρυθμίσεις. Ο σερβιτόρος ξεκινάει μόνο με τον όροφο. Κάθε γραμμή και κάθε πληρωμή κρατάει το όνομα.

Ένα PDA είναι κινητό στο ίδιο Wi-Fi, στον browser, με τον κωδικό του σερβιτόρου. Δύο άτομα στο ίδιο τραπέζι γράφουν στην ίδια παραγγελία, ο καθένας με το όνομά του.

Η βάση είναι ένα αρχείο στο `data/elia.sqlite`. Για να ξαναγίνει το δείγμα, σβήσε το αρχείο και ξανάτρεξε την εφαρμογή.

Ώρες στην οθόνη: Αθήνα.
